# 阶段性进展与结果边界

## 项目演化（仅列代表性阶段，不是全部补丁）
1. **阶段 02–05B**：构建 FR3、棒孔实体、碰撞、随机化、IK、控制/可视化的基础与物理诊断。
2. **v16 / v17.1**：学习和专家控制的初步实现，逐步加入真实安装随机化与传感接口。
3. **v17.3–v17.5 / v17.10–v17.11**：粗定位 BC 与完整 XYZ BC 的训练、独立学生闭环；全阶段 BC 闭环出现 coarse/fine stall。
4. **v18–v19.3**：RGB-D 学生观测、专家流程与视觉分离；v19.3 已见专家验证失败，尚无成功的全视觉学习验收记录。
5. **v21–v26**：相机、棒轴/孔心拟合、安装误差估计和 PPO/零 PPO 残差对照。
6. **v27–v31.6.1**：接触/孔壁开关反事实、轴向稳定、冻结单孔几何评估。
7. **v32.x**：六孔阵列与目标选择试验，目前未通过最终闭环验收。

## 已有数值证据及谨慎解释
- v17.5 全阶段 BC：120 个训练 epoch，最好 val MSE ≈0.00294；v17.10 约 0.001716，均不能代表在线成功。
- v31.6.1：27/30 单孔**几何**成功；2 个传感异常，1 个力过载；`all_completed_and_consistent=false`，物理碰撞接触证据尚不足。
- BC 粗定位配对：6 个相同随机种子，BC 达到10mm门槛平均 107.8 步，规则约76.2步；两组各6/6几何成功。只能说明这6对中BC没有速度优势。
- RGB-D 旧轨迹旁路诊断：远孔口有效帧 676/676，近孔口 4785/4811；有效帧XY误差P90分别约0.707mm、0.650mm。**这些不是无射线独立闭环的证据**。
- 六孔：最近一次 target_id=5 的 v32.2 BC 粗定位被 `SAFETY_Z_DRIFT` 在首步停止；不能归类为六孔插入成功。

## 待验证
- 仅由固定 RGB-D、关节FK与合法力/状态反馈完成单孔的观测和闭环。
- 学习型精细控制对执行的实际贡献，以及新的随机测试成功率。
- 独立物理接触确认、避免穿模、接触伙伴区分和数值稳定性。
- 六孔指定目标选择的完整闭环与独立测试。
