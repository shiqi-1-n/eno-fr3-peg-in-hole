# 单孔评估结果与指标边界

## 1. v31.6.1 冻结单孔评估

- **评估场景**：30 个随机种子；棒孔几何与随机安装配置沿用 v31.6.1。
- **观察结果**：27/30 轨迹达到程序定义的**几何插入成功条件**（保守比例 90.0%）。
- **剩余三条**：2 条传感无效；1 条接触力异常。
- **结论边界**：冻结评估报告的 `all_completed_and_consistent` 为 false，物理接触伙伴与子步接触确认尚不充分。因此不能称为“已验证 90% 物理插入成功”，也不能称为“BC/PPO 完整学习策略达到 90%”。

对应轻量报告：`evidence/v3161_frozen_eval/v3161_fresh30_20261104/report.json`。

## 2. 当前学习策略的实际作用

v31.6.1 的 COARSE 阶段先执行已训练的 BC 网络，未达门槛时规则伺服兜底；CENTER/PREAPPROACH/精细阶段主要执行规则反馈，PPO 残差强制清零。

六对相同随机种子的消融中，BC 与规则均有 6/6 几何成功，但规则在每一对中都更快达到粗定位门槛：平均约 76.2 步，BC 约 107.8 步。

所以当前数据**不支持宣称 BC 提高了单孔系统性能**。

## 3. RGB-D 视觉诊断

既有射线辅助控制轨迹的旁路记录中：远孔口采样帧 676/676 有效、近孔口 4785/4811 有效；有效帧的 XY 误差 P90 约 0.707/0.650 mm。这表明 RGB-D 感知值得复用，**不是**纯 RGB-D 从随机初始状态独立控制成功的证据。

## 4. 当前不足与后续验证

- 当前孔中心在线估计包含理想化的 PhysX 世界坐标扫描。
- 精细插入主要由规则控制，而不是已训练学习网络独立决策。
- 物理插入成功、接触确认与部分极端异常仍需额外验证。
- 六孔版本仍在探索，**尚未完成六孔闭环**。

后续应在新的、未参与调参的随机种子上，验证固定 RGB-D 独立观测、学习策略实际控制权和物理插入成功。
