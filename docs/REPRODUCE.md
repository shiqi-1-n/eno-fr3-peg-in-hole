# 复现入口与部署注意

- 系统来源：DGX Spark（aarch64），Isaac Lab 2.3.1 容器环境。
- 历史版本依赖较多，仓库保持 `scripts/` 和版本目录原相对路径，不保证克隆后无需修改就能运行所有旧版本。
- 先阅读 `scripts/v31_6_1_prelock_eval/README_中文.md`、`v3161_frozen_eval30/README_中文.md`、`scripts/v19_3/README_中文.md`，了解每种方案的目标和前提。
- `v3161_frozen_eval30` 带有冻结源码 SHA 校验：在新仓库里进行清理、调整或缺少权重时可能无法直接运行，不应绕过校验冒充原版复现。
- **不要重新运行原冻结30个种子作为训练或调参集**；需建立独立新种子。
- 本仓库只收集轻量源文件与报告。权重、RGB-D帧、视频、大数据集在本地备份，并见 `docs/MODEL_CHECKPOINTS.json` 的来源清单。
- 特权专家信息仅可用于明确标注的训练标签或离线评估；部署在线观测合规性需要单独核查。
