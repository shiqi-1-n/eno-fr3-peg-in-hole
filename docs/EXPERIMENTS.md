# 实验结果、证据与解释边界

> 本文刻意把 **训练损失、几何成功、物理插入、策略贡献、传感器合规性** 分开。它们不能互相替代。

## 2. v31.6.1 单孔冻结评估

- 测试数：30；达到**几何插入判据**：27；另外 2 条传感无效、1 条出现力异常。
- 数值上 27/30 = 90.0%，**但正式结果 `all_completed_and_consistent=false`**，不能称为“已验收 90% 物理插入”。
- PPO 动作残差被强制设为零；细控制以可观测反馈和规则控制为主。
- 当前感知中仍有理想化 PhysX 区域射线扫描；不能把旧系统的结果直接外推到纯 RGB-D 控制条件。
- 物理接触的参与对象识别、子步验证及稳定性仍有未解决问题。

证据：`evidence/v3161_frozen_eval/v3161_fresh30_20261104/report.json`。评估入口：`v3161_frozen_eval30/eval_v3161.py`。

## 3. 粗定位 BC vs 规则伺服（6 对种子）

| 指标 | BC_ON | SERVO_ONLY |
| --- | ---: | ---: |
| 达到 10 mm 门槛 | 6/6 | 6/6 |
| 到达 10 mm 的平均步数 | 107.8 | 76.2 |
| 几何成功 | 6/6 | 6/6 |

6/6 配对中规则伺服都更快；配对差（规则减 BC）均值约 −31.67 步。**这是六对种子的结论，不是总体统计保证；也不表示 BC 权重不存在或训练从未发生。**

仓库只包含配对清单 `evidence/bc_ablation_rollouts/paired_manifest.json`，不包含所有原始 rollout。完整逐种子数据需在原 DGX 保留。

## 4. RGB-D 旁路视觉审计

- 远孔口：676/676 帧有效，有效帧 XY 误差 P90 约 0.707 mm。
- 近孔口：4785/4811 帧有效，有效帧 XY 误差 P90 约 0.650 mm。
- 真值用于**离线测量误差审计**，不代表在线估计必然使用真值；但还需审查所有观测通路。
- 分桶基于离线真值，且这些图像是在射线辅助控制的旧轨迹中采集的；因此 **不能证明移除射线后，从随机起始位置进行 RGB-D-only 控制仍能成功**。

注意：上述统计是用户在 DGX 本地运行 `fr3_audit_followup.py` 后得到的控制台摘要；本仓库目前尚未保存完整逐帧审计日志。

## 5. 六孔探索

- 已有 2×3 孔阵列与指定目标的源码。
- v32.2 中一次指定 `target_id=5` 的测试，第 1 步触发 `SAFETY_Z_DRIFT`；`insertion_tested=false`。
- 这条实验仅能说明粗定位尚未通过，**不能统计为六孔插入成功，也不能由此判断 BC 在完整六孔任务的成功率**。

证据：`evidence/six_hole/v322_t5_seed02_bc_coarse01/v322_bc_coarse_result.json`。

## 6. 后续验收至少需要什么？

1. 确定最终允许的相机/本体/接触观测接口；不读取当次随机棒孔真值或依赖任意世界位置射线扫描兜底。
2. 用独立新种子同时测试非学习控制器和学习策略，保留完整执行日志与策略动作生效记录。
3. 明确真插入判据：深度、偏差、姿态、碰撞/接触证据、是否误插、力峰值及异常退出。
4. 冻结代码、模型、测试种子和成功判定，再统计单孔 ≥90% 的目标；六孔单独统计。
