# FR3 Peg-in-Hole｜Isaac Lab 单孔插入仿真与闭环控制

基于 **Franka FR3 + Isaac Lab 2.3.1** 搭建随机棒孔插入场景，实现从环境构建、感知估计到动作控制、评估记录的**单孔闭环原型**。

**当前状态：单孔阶段性验证；仍在完善感知与学习策略。** 本仓库不是最终任务验收报告，六孔插入尚未完成。

## 1. 任务与仿真环境

- **机器人**：Franka FR3（DGX Spark / Isaac Lab / PhysX）。
- **插入对象**：直径 **20 mm** 的圆柱棒与直径 **23 mm** 的孔，径向理论间隙 **1.5 mm**。
- **随机化**：孔在 **10 cm × 10 cm** 的工作区内随机平移；棒相对法兰存在未知的 **XY ±5 mm** 安装扰动。
- **约束**：在线控制不能直接读取无噪声的随机棒孔真实位姿作为策略观测；目标为训练策略网络并达到可靠插入。

环境包含棒孔碰撞几何、随机初始化、机械臂控制及轨迹诊断接口。当前使用 **XYZ 增量控制 + 逆运动学（IK）** 转换为 FR3 的关节动作，并通过安全门控限制危险运动。

## 2. 当前单孔闭环方案

```text
FR3 + 随机棒孔场景
        │
        ▼
  孔位与棒状态估计
        │
        ▼
  COARSE：BC 粗定位（超时后规则伺服兜底）
        │
        ▼
  CENTER / PREAPPROACH：反馈纠偏与安全接近
        │
        ▼
  精细插入：RGB-D / 本体反馈 + 规则控制及安全门控
        │
        ▼
  IK 执行 → 观测反馈 → 插入结果评估
```

### 感知

- **固定 RGB-D 相机**：用于孔中心、棒位置及棒轴姿态的几何估计；相机图像来自仿真渲染，使用预设标定。
- **PhysX 射线扫描**：当前单孔版本的孔位测量仍包含**理想化的世界坐标区域射线查询**。它不等于直接读取当次随机孔真值，但尚不能当作已经满足实体传感器约束的最终方案。
- **机器人状态**：关节信息、名义运动学、接触反馈和视觉质量等用于控制及安全判断。历史实现中部分本体状态读取方式仍需审计。

### 学习与控制

已训练 **BC 粗定位模型**。在当前闭环中，网络仅负责初期粗定位动作；后续精细对准和下插主要由反馈规则控制完成，**PPO 残差在该评估版本中被置零**。因此本系统应准确表述为**含 BC 的混合控制原型**，不能称为“训练网络独立完成全程插孔”。

## 3. 单孔阶段性结果

| 实验 | 结果 | 含义 |
| --- | --- | --- |
| v31.6.1 冻结 30 个随机场景 | **27 / 30** 达到几何插入判据（90.0%） | 另有 2 次传感无效、1 次接触力异常 |
| BC 与规则粗定位配对消融 | 6 对同种子，规则伺服均更快，两组各 6 / 6 几何成功 | 当前粗定位 BC **未体现效率优势** |
| RGB-D 旁路视觉审计 | 近孔口有效 4785 / 4811 帧；有效帧 XY 误差 P90 ≈ 0.65 mm |

详细的指标定义、条件和来源见 [实验说明](docs/RESULTS.md)；部分轻量 JSON 结果保存在 [`evidence/`](evidence/)。
